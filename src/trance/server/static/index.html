↻ Loops

A loop is a block of agents wired by outcome, saved under a name. A step can run one instead of a single agent — pick it in the Flow. Each agent's SUCCESS, FAILED and CHECK FAILED decides who runs next, or leaves the loop. The number on an arrow is how many times it may be taken before the loop gives up.

Written by agents with remember, read into every agent's prompt from the next step on. Decisions the team must share — a route and its payload, a port, where files live, how to run the tests. Correct or delete anything wrong here: a wrong fact misleads every agent that follows.
