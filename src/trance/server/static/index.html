Models

A model is everything needed to call it: the API it speaks, where it lives, the key, and the model id. Its name is the handle you attach to an agent — one thing to define, one thing to pick.

Step size

The orchestrator estimates every step in story points (1 = one small edit, 3 = one file end to end, 8 = a whole feature). Anything above this limit is broken into smaller steps before you see the flow — a step too big to picture is where an agent does the part it understood and reports success on all of it.

Git

Each step runs between two commits, so git log is the record of what every agent did — and a step that goes wrong has something to go back to. Turn this off and "revert on failure" on a step can do nothing.

When a step keeps failing

A block that has failed the same way three times will not be fixed by a fourth identical try — the loop varies the prompt and the fixing agent, but never the model. When the loops run out, trance can make one last attempt on a stronger model, with every previous failure in front of it, before halting.

Agents & permissions

Editing an agent type applies everywhere it's used. The remit is enforced at the tool boundary — a write outside it is refused, not just discouraged.

Step

↻ Loops

A loop is a block of agents wired by outcome, saved under a name. A step can run one instead of a single agent — pick it in the Flow. Each agent's SUCCESS, FAILED and CHECK FAILED decides who runs next, or leaves the loop. The number on an arrow is how many times it may be taken before the loop gives up.

🧠 Project memory

Written by agents with remember, read into every agent's prompt from the next step on. Decisions the team must share — a route and its payload, a port, where files live, how to run the tests. Correct or delete anything wrong here: a wrong fact misleads every agent that follows.
